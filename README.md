# sdSCA: Multi-Strategy Self-Adaptive Differential

# Sine-Cosine Algorithm for Multi-Robot Path Planning

## Overview

Python implementation of sdSCA algorithm based on the paper:
"Multi-strategy and self-adaptive differential sine-cosine
algorithm for multi-robot path planning"
by Akay & Yildirim (2023)

## Algorithm Features

- 4-strategy pool (SCA + 3 DE variants)
- Self-adaptive roulette wheel selection
- Online multi-robot path planning
- Static and dynamic obstacle avoidance

## Requirements

- Python 3.11+
- NumPy, Matplotlib, SciPy, Pandas

## Installation

pip install -r requirements.txt
